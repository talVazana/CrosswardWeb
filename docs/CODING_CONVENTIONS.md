# Coding Conventions

- **Language:** TypeScript for frontend.
- **Frontend Framework:** React (Vite recommended).
- **Backend/Db:** Firebase (Firestore).
- **Styling:** CSS / Tailwind (TBD based on UI needs).
- **RTL:** Native HTML `dir="rtl"` for the crossword components.
- **Testing:** Vitest / Jest for unit tests.

## Rules
- Keep puzzle data separate from UI state.
- Keep tests alongside components.
- Code should be clean, readable, and well-structured.
